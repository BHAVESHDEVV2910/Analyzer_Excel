# 📊 Analyzer Excel

## 📌 Project Overview

**Analyzer Excel** is a practical Microsoft Excel project developed to strengthen data analysis, spreadsheet management, and analytical problem-solving skills.

The project demonstrates how Microsoft Excel can be used to work with structured data, perform calculations, organize information, analyze datasets, and generate meaningful results from raw data.

This project is part of my **Data Analytics learning journey** and focuses on developing practical Excel skills that can be applied to real-world business and analytical scenarios.

The main workbook included in this repository is:

**`PR. 2 Analyzer.xlsx`**

---

# 🎯 Project Objectives

The primary objectives of this project are:

- Understand how to work with structured Excel data.
- Analyze data using Microsoft Excel.
- Apply formulas and functions for calculations.
- Organize and manage spreadsheet data.
- Perform data sorting and filtering.
- Extract useful information from datasets.
- Develop analytical thinking and problem-solving skills.
- Understand the importance of data preparation before analysis.
- Build practical Excel skills required for Data Analytics.
- Improve the ability to convert raw data into useful information.
